# ISO 27001 Risk Assessment and Compliance Project

## Project Overview
This is a self-learning project based on ISO/IEC 27001:2022. It demonstrates basic information security risk assessment and compliance tracking using Microsoft Excel.

## Project Objectives
- Identify and document information assets.
- Assess information security risks.
- Document risk treatment plans.
- Track security control testing.
- Maintain evidence and finding records.
- Monitor compliance status using an Excel dashboard.

## Tools Used
- Microsoft Excel
- ISO/IEC 27001:2022 framework concepts

## Project Workbook Sections
1. Asset Inventory
2. Risk Register
3. Risk Treatment
4. Control Testing
5. Evidence Tracker
6. Finding Tracker
7. Security Compliance Tracker
8. Dashboard

## Skills Demonstrated
- Risk assessment documentation
- Security control tracking
- Compliance documentation
- Excel reporting and dashboards

## Disclaimer
This is a self-learning practice project. It is not an official ISO 27001 certification or an independent audit report.
